# Smart Coal Governance Portal

A web-based coal mine governance portal for field officers and supervisors, with offline-oriented workflows, geo-tagged inspections, compliance records, reports, and AI-anomaly views.

## Project Structure

- `index.html` - Page structure and accessible markup
- `css/styles.css` - Portal styles and responsive layout
- `js/app.js` - Application logic and interactions

## Run Locally

Open `index.html` in a modern browser, or serve the project from this directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
